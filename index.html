Creatroka — Book Demand Forecasting & Stock Optimization

TYPE
Thesis Project (Tugas Akhir)
SEMESTER
Semester 7
STACK
Python, Flask, XGBoost, SQLite
ROLE
Full-stack Developer

Creatroka is a production-grade web application designed for small bookstores to predict future book demand and optimize inventory levels. The system uses XGBoost regression models trained on historical sales data enriched with feature engineering — including Hijri calendar dates, Indonesian national holidays, Ramadan periods, and weekend/month-end patterns.

Key features of the system:

  • Dashboard with stock status indicators, weekly sales trend charts, and best-seller tables
  • Data Preparation module: dataset upload (Excel/CSV), product name mapping, and automated feature engineering
  • Model Management: train, compare, and activate XGBoost model versions with R², MAE, and RMSE metrics
  • Demand Prediction: multi-week forecasting with interactive Plotly visualizations
  • Stock Optimization: Safety Stock & Reorder Point (ROP) calculations based on configurable lead time and service level
  • Admin profile management with account statistics
  • Modular Flask architecture with Blueprints, service layer, and clean separation of concerns
Python Flask XGBoost Scikit-learn Plotly Pandas SQLite Hijri Calendar Feature Engineering

Predicting Worker Productivity in Garment Companies

TYPE
Capstone Project — MSIB Cakap
PATH
Data Science B
DATASET
1,197 rows × 15 features
MODELS
7 algorithms benchmarked

End-to-end regression project predicting actual productivity of garment factory workers using the UCI Garment Worker Productivity dataset. The project covers the complete data science pipeline from data understanding through model deployment and explainability.

Methodology and process:

  • Data Understanding: explored 15 features (SMV, overtime, incentive, idle time, number of workers, etc.)
  • Data Cleaning: handled missing values in WIP column (506 nulls), outlier detection and treatment
  • Feature Selection: compared Pearson Correlation, SelectKBest, and Recursive Feature Elimination (RFE) methods
  • Benchmarked 7 models: Linear Regression, KNN, Decision Tree, Random Forest, SVM, MLP Neural Network, and XGBoost
  • Hyperparameter tuning with Grid Search and Cross-Validation
  • Model explainability using SHAP (SHapley Additive exPlanations) values
  • Comprehensive visualization with Matplotlib and Seaborn
Python Pandas NumPy Scikit-learn XGBoost SHAP Matplotlib Seaborn Google Colab

TYPE
Desktop Programming Course
SEMESTER
Semester 4
STACK
Java, Swing, MySQL
ARCHITECTURE
MVC Pattern

A comprehensive Java Swing desktop application for managing boarding house (kost) rental operations. The system handles the full lifecycle of property rental — from room registration and tenant management to rental transactions and financial reporting.

System modules and features:

  • Multi-role login system: Admin and Property Owner (Pemilik) dashboards
  • Room Management (Data Kost): CRUD operations for boarding room listings with details and pricing
  • Tenant Management (Penyewa): register, update, and track tenant profiles
  • Rental Transactions (Data Sewa Kost): process check-in/check-out with automated billing
  • Reporting: generate rental reports (LaporanSewa) and room occupancy reports (LaporanKost)
  • MySQL database backend with JDBC connectivity for persistent data storage
  • Clean separation of concerns: form layer, controller classes (CAdmin, CLogin, CPenyewa, etc.), and database layer
Java Swing GUI MySQL JDBC CRUD MVC NetBeans Reporting
